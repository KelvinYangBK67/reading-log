# 閱讀

一個使用 Flask 與 SQLite 製作的本機個人閱讀紀錄。

## 需求

- Python 3.10 或更新版本

## 快速啟動

直接雙擊 `run.bat`。它會在需要時安裝套件、檢查連接埠 `5000`，並自動開啟瀏覽器。如果 `5000` 已被其他程式使用，會改用 `5001` 到 `5010` 之間的第一個可用連接埠。

若要停止應用程式，請回到啟動視窗並按 `Ctrl+C`。

## 手動安裝與執行

```powershell
python -m pip install -r requirements.txt
python app.py
```

接著開啟終端機顯示的本機網址，通常是 `http://127.0.0.1:5000`。

## 資料庫與備份

資料會儲存在專案目錄內的 `reading.db`。第一次執行時會自動建立。

備份前請先停止應用程式，再將 `reading.db` 複製到安全的位置即可。還原時，將備份檔複製回專案目錄並命名為 `reading.db`。
